# Starfall 坠落之星 · 天气倍率

- 作者: 不是现在
- 出处: TShock插件库
- 在**原版（vanilla）服务器**上复刻 tModLoader 模组 [Fargo's Fallen Stars](https://steamcommunity.com/sharedfiles/filedetails/?id=2797510870) 的坠落之星功能，并附加原版天气事件（下雨 / 风 / 沙尘暴 / 钱币雨 / 陨石雨）的倍率控制。

## 功能

- 落星频率倍率（坠落动画/弹幕的生成速率，默认 2 倍）。
- 白天可落星（默认开），白天频率可单独设为夜晚的倍率（默认 0.1 倍）。
- 落星掉落表可调（默认 50% 坠落之星 / 40% 魔力水晶 / 10% 生命水晶）。
- 下雨、风、沙尘暴倍率可调；钱币雨/陨石雨各自拆成 **概率倍率 + 产出倍率**（默认均为 2 倍）。
- 配置文件键名全部为中文。

> 关键背景：原版落星生成完全在客户端（`Main.netMode != 2`），服务端无法直接改它的倍率；本插件改为由**服务端额外生成**落星弹幕（Projectile type 12）并自行结算掉落，叠加在原版之上。天气事件则本来就是服务端权威的，状态通过 7 号包（WorldData）同步。

## 指令

权限节点：`starfall.admin`

```
/sf                     查看全部设置
/sf status              查看全部设置
/sf rate <倍率>         设置落星频率倍率
/sf day <倍率>          设置白天频率倍率（相对夜晚）
/sf rain <倍率>         设置下雨倍率
/sf wind <倍率>         设置风倍率
/sf sand <倍率>         设置沙尘暴倍率
/sf coin <倍率>         设置钱币雨概率倍率
/sf coinyield <倍率>    设置钱币雨产出倍率
/sf meteor <倍率>       设置陨石雨概率倍率
/sf metyield <倍率>     设置陨石雨产出倍率
/sf drop list           查看掉落表
/sf drop add <物品ID> [数量] [权重]
/sf drop clear          清空掉落表
/sf toggle              总开关
/sf stars               落星开关
/sf weather             天气增强开关
/sf spawn [数量]        立即生成落星（测试，1-200）
/sf reload              重新加载配置
```

## 配置

首次启动后生成于 TShock 存档目录 `Starfall.json`，键名全中文：

```jsonc
{
  "启用": true,                 // 总开关
  "启用落星": true,             // 是否启用落星增强
  "启用天气增强": true,         // 是否启用天气倍率

  "落星频率倍率": 2.0,          // 坠落动画(弹幕)生成速率倍率，1.0 ≈ 原版夜晚总量
  "白天可落星": false,          // 原版仅夜晚落星；默认关闭（开启后也只在“地表层”玩家头顶落）
  "白天频率倍率": 0.1,          // 白天频率相对夜晚的倍率
  "落星伤害": 500,              // 弹幕伤害；>500 会让原版额外掉一个坠落之星(75)
  "落星掉落表": [
    { "物品ID": 75,  "数量": 1, "权重": 50.0 },  // 坠落之星 50%
    { "物品ID": 109, "数量": 1, "权重": 40.0 },  // 魔力水晶 40%
    { "物品ID": 29,  "数量": 1, "权重": 10.0 }   // 生命水晶 10%
  ],

  "下雨倍率": 2.0,              // 下雨出现频率 ×2
  "风倍率": 2.0,                // 风力强度 ×2（更易出现大风天）
  "沙尘暴倍率": 2.0,            // 沙尘暴出现频率 ×2
  "钱币雨概率倍率": 2.0,        // 每场雨开始时钱币雨跟随发生的概率 ×2（原版约 1/25）
  "钱币雨产出倍率": 2.0,        // 一场钱币雨的总落币“预算” ×2
  "陨石雨概率倍率": 2.0,        // 每夜陨石雨发生概率 ×2（原版约 1/150，需已击败克脑/大虫）
  "陨石雨产出倍率": 2.0         // 一场陨石雨的流星总数 ×2
}
```

### 倍率含义

| 配置项 | 作用对象 | 实现方式 |
| --- | --- | --- |
| 下雨倍率 | 下雨**出现频率** | 在原版判定上补掷 `(倍率-1)×原版概率`，命中即 `Main.StartRain()` |
| 风倍率 | **风力强度** | 服务端刷新风力目标时放大 `Main.windSpeedTarget` 并夹到 ±0.8 |
| 沙尘暴倍率 | 沙尘暴**出现频率** | 补掷概率，命中即置位 `Sandstorm.Happening` 并发 7 号包 |
| 钱币雨概率倍率 | 钱币雨**发生概率** | 每次开始下雨时在原版 1/25 之外补掷 `(倍率-1)×1/25`，命中即按原版规则开启钱币雨 |
| 钱币雨产出倍率 | 钱币**总量** | 钱币雨开始时放大预算 `Main.coinRain` |
| 陨石雨概率倍率 | 陨石雨**发生概率** | 每次入夜补掷 `(倍率-1)×1/150`（与原版一致需 `downedBoss2`/克脑或大虫），命中即 `WorldGen.StartMeteorShower()` |
| 陨石雨产出倍率 | 陨石**总数** | 陨石雨开始时放大 `WorldGen.meteorShowerCount` |

> 倍率 **≥ 1** 才有效（原版逻辑无法被降低，只能叠加增益），并会被收敛到合理上限。

## 注意事项

1. 落星由服务端权威模拟：`Projectile.NewProjectile(...)` 在服务端要求 `Owner == Main.myPlayer`（服务器为 255），否则不会同步/结算。
2. 自定义掉落：把 `落星伤害` 设为 ≤ 500 可关闭原版“落地掉坠落之星”的判定（原版条件 `type == 12 && damage > 500`）；调回 > 500 则原版会额外掉一个，与本插件掉落表叠加。
3. 白天落星：原版落星白天自毁条件是 `type == 12 && damage == 1000`，默认伤害 500 可避开。
4. 客户端原版落星仍在：本插件是“叠加”一个服务端来源。
5. 天气是全局世界状态，影响所有玩家，不能按玩家区分。
6. 每 tick 自带最多生成 20 颗的安全上限，避免极端倍率造成卡顿。

## 更新日志

### v2.0.2
- 修复落星出现在地下的问题：遵循原版「仅地表层玩家头顶落星」的规则，地下/洞穴玩家不再触发落星。
- `白天可落星` 默认改为关闭（原版仅夜晚落星），开启后仍只在地表层玩家头顶生效。

### v2.0.1
- 钱币雨/陨石雨倍率拆成 **概率倍率 + 产出倍率** 两组键（默认 2×2）：
  - `钱币雨概率倍率`：每次开始下雨时，在原版 1/25 之外补掷 `(倍率-1)×1/25`，命中即按原版规则开启钱币雨。
  - `钱币雨产出倍率`：钱币雨开始时放大预算 `Main.coinRain`。
  - `陨石雨概率倍率`：每次入夜补掷 `(倍率-1)×1/150`（与原件一致需已击败克脑/世界吞噬者），命中即 `WorldGen.StartMeteorShower()`。
  - `陨石雨产出倍率`：陨石雨开始时放大流星总数 `WorldGen.meteorShowerCount`。
- 新增 `/sf coinyield`、`/sf metyield` 命令；`/sf coin`、`/sf meteor` 现在设置"概率"。
- 旧键 `钱币雨倍率` / `陨石雨倍率` 已移除（会被忽略并回落默认值）。

### v2.0.0
- 移植为 TShock 6.2.1 / net9.0 插件，发布到本仓库。
- 落星改为服务端主动生成弹幕（type 12）并接管掉落。
- 配置键名改为全中文；提供落星掉落表。
- 新增下雨 / 风 / 沙尘暴 / 钱币雨 / 陨石雨倍率。
- 提供 `/sf` 系列命令。
