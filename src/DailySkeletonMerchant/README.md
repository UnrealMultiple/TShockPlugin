# DailySkeletonMerchant 骷髅商人每日到访

- 作者: 不是现在
- 目标框架: .NET 9 / TShock 6.x（实测 6.1.0、6.2.1）

## 行为

- **每天上午出现一次**：每个游戏日 4:30 之后的第一秒判定，在世界出生点附近的固定位置生成一名骷髅商人（NPC 453）。
- **位置固定**：锚点由出生点坐标按固定顺序逐圈搜索得出（脚下有实地、身体两格与两侧为空、不泡水、不在地牢砖上），搜索顺序只取决于出生点，所以同一个出生点每天都是同一个格子。
- **多出生点种子**：有些地图种子会按队伍分配不同出生点。这时插件从所有出生点里**随机挑一个**再用（该种子下每天不一定落在同一个出生点）。
- **怪出生点也能应付**：世界生成给的出生点常常站不住人（墙里、水里、地牢砖上、悬空平台）。插件会在每个出生点周围先按 40 格找，实在不行放宽到 120 格再找一遍。
- **人离开就离开**：插件生成的骷髅商人在 50 格（原版 NPC 反卸载半径 800 像素）内没有在线玩家时就离场，方式与原版 `UnspawnTravelNPC` 一致（清 `active`/`life` 并广播 23 号包）。
- **一个游戏日内不再出现**：当天出现过之后，无论他是自己离开还是被玩家打死，当天都不会再来；等到第二天 4:30 重新判定。
- **死亡不补位**：他只有 250 点生命，被打死就等下一天。
- **场上已有骷髅商人就不干预**：洞穴里自然刷出来的、昨天留下的、管理员手动召唤的，只要场上已经有一只 453，插件当天就不生成第二只、也不干预它，按原版正常跑。
- **没人在线时不占用当天的机会**：空服世界不推进，有人进服后会在上午窗口内补上判定。
- **无配置文件、无指令、无广播**，行为全部固定如上。

## 货品仍是原版

骷髅商人的商品和价格本来就是**客户端按月相现场计算**的：

- 商品表：`Chest.SetupShop(453)`，每次打开商店界面时按 `Main.moonPhase` / `Main.dayTime` 现场生成；
- 价格系数：`ShopHelper.GetSkeletonMerchantPrices`，月相满月 1.4 倍、白天再加 0.1；
- `Main.moonPhase` 由 `Main.UpdateTime` 在**每天清晨 4:30** 递增一次。

所以本插件**不缓存、不广播、不改写任何商店数据**：只要人在场，第二天清晨就会自动随原版换货，这也正是"保持原版货品每天清晨变更"的做法。

另外注意原版的一个细节：这些区域判断用的是**打开商店的那个玩家所在的位置**，不是商人的位置——他站在出生点，玩家在墓地打开他的商店，拿到的是墓地变体的货。
