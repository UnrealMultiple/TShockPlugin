# AutoEat 自动进食 / 续 buff（TShock 插件）

自动为玩家维持食物饱食 buff：**真实消耗背包里的食物**进食，或**不消耗物品直接续 buff**。

核心规则 —— **仅续「激活过、且刚过期」的**：

1. 玩家在线期间曾激活过的食物 buff / 增益，才会被跟踪；
2. 跟踪中的 buff 消失（刚过期）时才尝试续上；
3. 玩家从未获得过的 buff 一律不补（不会给从不吃饭的玩家硬塞 buff）。

## 两条续期通道

| 通道 | 行为 | 说明 |
| --- | --- | --- |
| **续食物** | 从背包真实消耗一份食物，按食物品质给对应 buff | 食物识别不写死物品 ID：凡 `buffType` 为 26/206/207 的物品都算食物 |
| **续buff** | 不消耗物品，直接补 `buff列表` 内的 buff | 可续任意 buff（不限于食物），同样只续「激活过且刚过期」的 |

两者同时启用时：**优先续食物**（吃背包里的），背包没食物时由 **续buff** 兜底。
buff 档位：`26` 吃得好 < `206` 很满意 < `207` 吃得很饱。过期 206 时优先吃 206 食物，其次吃更高档（升级），最后吃低档保底（可关闭）。

## 食物 buff（参考）

| buff | ID | 常见食物 |
| --- | --- | --- |
| 吃得好 Well Fed | 26 | 熟鱼、熟虾、苹果、薯条等 |
| 很满意 Plenty Satisfied | 206 | 汉堡、披萨、墨西哥卷饼等 |
| 吃得很饱 Exquisitely Stuffed | 207 | 顶级料理（如海鲜大餐、龙虾尾等） |

## 构建

需要 .NET SDK 9+（本机已验证：.NET 10 SDK，TShock 6.1.0 引用包）。

```bash
cd AutoEat
dotnet build -c Release
```

产物：`bin/Release/net9.0/AutoEat.dll`

- 引用包 `TShock 6.1.0`（NuGet，仅参与编译），与你的服务器版本一致。
- 若服务器是 TShock 5.x：把 csproj 的 `TargetFramework` 改为 `net6.0`、`TShock` 版本改为 `5.2.0` 后重新编译。

## 安装

1. 把 `AutoEat.dll` 放进服务器 `ServerPlugins/` 目录；
2. 重启服务器（或由 AutoPluginManager 热载）；
3. 首次启动会在 `tshock/AutoEat.json` 生成配置文件。

## 配置文件 `tshock/AutoEat.json`

```json
{
  "全局启用": true,          // 总开关
  "默认开启": true,          // 新玩家默认是否启用（可用 /autoeat 个人覆盖）
  "检查间隔(秒)": 1,         // 扫描频率
  "刚过期判定(秒)": 30,      // buff 消失后多久内视为「刚过期」；窗口内没续上就放弃。
                              // 找不到食物时会在窗口内持续重试（比如中途捡到食物）
  "进食提示": true,          // 进食/续期时的聊天提示
  "续食物": {
    "启用": true,
    "允许低档替补": true,     // 同档食物吃完时是否吃低档食物保底（高档食物始终可用）
    "忽略物品ID": [],         // 永不自动食用的食物 ID（如收藏用金美食）
    "仅白名单物品ID": []      // 非空时只吃列表内的食物
  },
  "续buff": {
    "启用": true,
    "buff列表": [26, 206, 207], // 允许直接续上的 buff（不消耗物品），可加任意 buff ID
    "时长(秒)": 480           // 直接续 buff 给予的时长
  }
}
```

改完配置后 `/reload` 或 `/autoeat reload` 生效。

## 指令

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `/autoeat`（`/ae`） | 开关个人自动进食 | `autoeat.use` |
| `/autoeat status` | 查看个人开关、续期配置、已跟踪/待续 buff | `autoeat.use` |
| `/autoeat reload` | 重载配置文件 | `autoeat.use` |

## 行为细节与注意事项

- **触发条件**：buff 剩余时间归零消失的那一刻（下个检查周期检测到）才续，不刷新、不叠加已有 buff。
- **玩家跳过条件**：离线、未登录、死亡的玩家不处理。
- **食物消耗**：服务端扣减堆叠并发送 5 号包（PlayerSlot）同步背包；SSC 模式下每次进食自动存档（`SaveServerCharacter`）。
- **直接续 buff** 用 `SetBuff(..., bypass: true)`，不受 Bouncer 威胁状态拦截。
- **激活记录**按账号/UUID 在内存中记忆（`/autoeat status` 可查看），服务器重启后清空；重启后首次获得的 buff 重新开始跟踪。
- **SSC 重连清 buff**：SSC 模式下玩家重连时 buff 会被清空，这会被视为「刚过期」并自动续上（因为该 buff 之前激活过）；不想续就把对应 buff 从 `buff列表` 移除或关闭 `续食物`。
- 与 PermaBuff / EndureBoost 同时使用时功能可能重叠：PermaBuff 是无条件永久 buff，本插件只在「激活过且刚过期」时续，二者不冲突但效果叠加。
