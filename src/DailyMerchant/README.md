# DailyMerchant 旅商每日到访

- 作者: 不是现在
- 目标框架: .NET 9 / TShock 6.x（实测 6.1.0、6.2.1）
- 无需客户端 Mod

## 原理

原版「流动旅商」（Travelling Merchant，NPC 368）不是每天掷一次骰，而是**每 tick 掷一次**：
上午 4:30–12:00（27000 tick）每 tick 有 `1/108000` 的概率，所以一天只有
`1 - (107999/108000)^27000 ≈ 22.12%` 的到访机会；玩家入睡时概率 ×5，
日晷 / Moondial 生效时永不出现。

本插件**不自己造 NPC**，只把判定频率提上来：

- 每秒扫一次，条件与原版逐条对齐（白天、4:30 起 450 分钟内、城镇 ≥2 位 NPC、日晷不生效、非月食/入侵）；
- 条件满足就调用游戏自己的 `WorldGen.SpawnTravelNPC()`；
  商品池（`Chest.SetupTravelShop` + `NetMessage.SendTravelShop`）、客户端同步、到访/离开播报全部走原版；
- 条件不满足（例如城镇 NPC 还没房子）就**静默跳过**，等下一次判定，不做任何强行补位。

黄昏离场、入夜自动清场这些本来就是原版行为，插件不重复实现。
早上到访后被玩家杀掉，第二天会重新判定（保留原版"杀掉重掷商品池"的玩法）。

无配置文件，行为固定为"每天 100% 到访"。

## 指令

| 语法 | 权限 | 说明 |
|-------|:----:|:----:|
| /merchant summon | tshock.admin | 立刻召唤旅商（/merchant 召唤） |
| /merchant despawn | tshock.admin | 请旅商离场，走原版 `UnspawnTravelNPC`（/merchant 离开） |
| /merchant check | tshock.admin | 手动跑一次到访判定（/merchant 检查） |
| /merchant status | tshock.admin | 概率、时刻、场上数量与坐标、城镇住房诊断（/merchant 状态） |

别名：`/merchant`、`/旅商`、`/dailymerchant`。

## 排查

`/merchant status` 会直接说明为什么没来：

```
[旅商] 城镇：2 位 NPC（已入住 0，待搬入空房 0）
[旅商] 判定：城镇里有 2 位 NPC，但都没住进房子，原版没有落脚点（静默等待中）
[旅商] 原版生成：原版拒绝：既没有已入住的城镇 NPC，也没有可搬入的空房
```

- `已入住 0` → 城镇 NPC 还没房子，原版不会生成旅商；等玩家把城镇 NPC 安置好即可。
- `日晷 / Moondial 生效中` → 原版此时本来就不掷骰，等日晷结束。
- `现在是夜晚 / 已过上午4:30 + 450 分钟` → 明天上午再来。

**空服注意**：Terraria 专用服务器在无玩家在线时不推进世界，插件的每秒自动判定不会触发；
有人进服后会自动补上判定。控制台可以用 `/merchant check` 手动跑一次（自动化测试也走这个入口）。
