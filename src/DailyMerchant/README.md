# DailyMerchant 商人每日到访

- 作者: 不是现在
- 目标框架: .NET 9 / TShock 6.x（实测 6.1.0、6.2.1）
- 无需客户端 Mod

一个插件管两个商人，各自一个开关，默认都开：

| 开关（配置文件 `DailyMerchant.json`） | 默认 | 作用 |
|---|:---:|:---|
| `启用旅商每日到访` | 开 | 旅商（NPC 368）每天必到 |
| `启用骷髅商人每日到访` | 开 | 骷髅商人（NPC 453）每天上午出现在出生点附近 |

配置文件首次启动时自动生成在 TShock 的配置目录（`TShock.SavePath` 下，服务器上通常是 `tshock/DailyMerchant.json`），改完用 `/tconfig reload` 热重载。

## 旅商（NPC 368）

原版「流动旅商」不是每天掷一次骰，而是**每 tick 掷一次**：
上午 4:30–12:00（27000 tick）每 tick 有 `1/108000` 的概率，所以一天只有
`1 - (107999/108000)^27000 ≈ 22.12%` 的到访机会；玩家入睡时概率 ×5，
日晷 / Moondial 生效时永不出现。

本插件**不自己造 NPC**，只把判定频率提上来：

- 每秒扫一次，条件与原版逐条对齐（白天、4:30 起 450 分钟内、城镇 ≥2 位 NPC、日晷不生效、非月食/入侵）；
- 条件满足就调用游戏自己的 `WorldGen.SpawnTravelNPC()`；
  商品池（`Chest.SetupTravelShop` + `NetMessage.SendTravelShop`）、客户端同步、到访/离开播报全部走原版；
- 条件不满足（例如城镇 NPC 还没房子）就**静默跳过**，等下一次判定，不做任何强行补位。

黄昏离场、入夜自动清场这些本来就是原版行为，插件不重复实现。
早上到访后被玩家杀掉，第二天会重新判定（保留原版"杀掉重掷商品池"的玩法）。

## 骷髅商人（NPC 453）

- **每天上午一次**：每个游戏日 4:30 之后的第一秒判定，白天且在 4:30–12:00 窗口内、日晷不生效时生成。
- **位置固定**：锚点由出生点坐标按固定顺序逐圈搜索得出（脚下有实地、身体两格与两侧为空、不泡水、不在地牢砖/蓝砖上），同一个出生点每天都是同一个格子。
- **多出生点种子**：有些地图种子会按队伍分配不同出生点（`Main.teamBasedSpawnsSeed`），此时从所有出生点里**随机挑一个**再用。
- **怪出生点兜底**：世界生成给的出生点常常站不住人（墙里、水里、悬空平台），先按 40 格找，全都不行再放宽到 120 格。
- **时间到且没人了他才走**：离场要同时满足两个条件——天黑（时间到了）**并且** 800 像素（50 格）内没有玩家。只天黑而身边还有人的时候他会照常站着，不会突然消失；等人走远了才离场。清场方式同原版 `UnspawnTravelNPC`（清 `active`/`life` + 广播 23 号包），只处理插件自己生成的那一只，洞穴里刷到的、别的插件召唤的一概不动。
- **不会被原版按距离卸载**：原版会清理离所有玩家 2000 像素（125 格）之外的 NPC，骷髅商人不是城镇 NPC，一走远就会被清掉；插件每秒把原版的卸载计时按回 0，并在他被清掉且附近有玩家时原位补回（被打死的仍然不补位）。
- **一个游戏日只来一次**，被玩家打死也不补位，第二天上午再来。
- **场上已有就不干预**：洞穴里刷到的、别的插件召唤的，只要场上有 453，当天不生成第二只。

**货品完全沿用原版**：商品表本来就是客户端按 `Main.moonPhase` 现场计算的（`Chest.SetupShop(453)` + `ShopHelper.GetSkeletonMerchantPrices`），
而 `Main.moonPhase` 由 `Main.UpdateTime` 在每天清晨 4:30 递增一次。所以插件不缓存、不广播、不改写任何商店数据：
只要人在场，第二天清晨就自动随原版换货。

> 原版的一个细节：这些区域判断用的是**打开商店的那个玩家所在的位置**，不是商人的位置。

## 指令

| 语法 | 权限 | 说明 |
|-------|:----:|:----:|
| /merchant summon | tshock.admin | 立刻召唤旅商（/merchant 召唤） |
| /merchant despawn | tshock.admin | 请旅商离场，走原版 `UnspawnTravelNPC`（/merchant 离开） |
| /merchant check | tshock.admin | 手动跑一次到访判定（旅商与骷髅商人各一次） |
| /merchant status | tshock.admin | 时刻、月相、场上数量、城镇住房诊断、开关状态（/merchant 状态） |

别名：`/merchant`、`/旅商`、`/dailymerchant`。
指令只对旅商有 summon/despawn；骷髅商人由插件按上面的规则自己管。

## 排查

`/merchant status` 会直接说明为什么没来：

```
[旅商] 城镇：2 位 NPC（已入住 0，待搬入空房 0）
[旅商] 判定：城镇里有 2 位 NPC，但都没住进房子，原版没有落脚点（静默等待中）
[旅商] 原版生成：原版拒绝：既没有已入住的城镇 NPC，也没有可搬入的空房
[骷髅商人] 当前：白天 04:31，月相 1，场上骷髅商人 0 位，位置 当前不在场
[骷髅商人] 出生点：(3568, 1837)，判定：条件已满足，将出现在出生点附近
```

- `已入住 0` → 城镇 NPC 还没房子，原版不会生成旅商；等玩家把城镇 NPC 安置好即可。
- `日晷 / Moondial 生效中` → 原版此时本来就不掷骰，等日晷结束。
- `现在是夜晚 / 已过上午4:30 + 450 分钟` → 明天上午再来。
- 骷髅商人 `暂无玩家在线` → 没人在线，空服世界不推进，等有人进服再判定。
- 开关关了 → status 会显示 `已在配置里关闭`。

**空服注意**：Terraria 专用服务器在无玩家在线时不推进世界，插件的每秒自动判定不会触发；
有人进服后会自动补上判定。控制台可以用 `/merchant check` 手动跑一次（自动化测试也走这个入口）。
