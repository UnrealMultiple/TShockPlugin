# NurseHeal 护士治疗

- 作者: 不是现在
- 适用: TShock 6.x · Terraria 1.4.5.x

与护士对话 → 按**原版护士真实定价**自动扣钱 → 回满血并**移除护士可移除的减益**。
无需玩家点原版「治疗」按钮，也不由客户端决定扣多少钱。

## 行为（固定，无配置文件）

| 项目 | 取值 |
| --- | --- |
| 回血量 | 始终回满（与原版一致） |
| 减益 | 一并移除护士可移除的减益；移除不了的（`NurseCannotRemoveDebuff`）不计费也不移除 |
| 价格 | 原版公式 × 快乐度（`ShopHelper.GetShoppingSettings`）× 折扣卡（物品 854 / 指环 3035，×0.8） |
| 距离 | 服务端 800 像素校验 |
| 付费方式 | 扣背包/存钱罐/保险箱里的原版钱币；找零按铂金→金→银→铜 999 堆叠重发，放不下整体回滚并拒绝本次治疗 |
| 冷却 | 无，每次对话即时结算 |

## 定价公式（与原版逐项一致）

```
基价 = 缺失生命(statLifeMax2 - statLife) + 可计费减益数 × 100
世界进度(取最高档): 眼×3 → 脑/世吞×10 → 骷髅王/蜂后×25 → 困难模式×60
                    → 机械王后×100 → 世纪之花×150 → 石巨人×200 封顶
专家/大师 ×2；折扣卡 ×0.8；快乐度 0.75~1.5（含 1000 拒绝档钳制）
```

## 部署

只需把 `NurseHeal.dll` 放进服务器 `ServerPlugins/` 重启生效，无依赖 DLL。
