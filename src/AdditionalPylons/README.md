# AdditionalPylons 放置更多晶塔权

- 作者: Stealownz，肝帝熙恩优化1449
- 出处: [github](https://github.com/Adventure-Terraria-Server-Project/AdditionalPylons-Plugin)
- 自定义 11 种晶塔可放置的数量，每种上限至少为一个；可配置是否跳过传送所需的城镇 NPC 和群落检查。
- v1.1.0 更新代码及本次更新说明由 AI 生成，基于原作者插件升级，保留原作者署名及出处。

## 指令

| 语法 |        权限        |    说明    |
|----|:----------------:|:--------:|
| 无  | AdditionalPylons | 放置更多晶塔权限 |

## 配置
> 配置文件位置：tshock/AdditionalPylons.zh-CN.json
```json5
{
  "丛林晶塔数量上限": 2,
  "森林晶塔数量上限": 2,
  "神圣晶塔数量上限": 2,
  "洞穴晶塔数量上限": 2,
  "海洋晶塔数量上限": 2,
  "沙漠晶塔数量上限": 2,
  "雪原晶塔数量上限": 2,
  "蘑菇晶塔数量上限": 2,
  "万能晶塔数量上限": 2,
  "地狱晶塔数量上限": 2,
  "微光晶塔数量上限": 2,
  "晶塔无需城镇环境": false
}
```

- 数量上限按当前手持晶塔类型独立计算，配置值小于 1 时按 1 处理。
- `晶塔无需城镇环境` 默认为 `false`，保留原版传送检查；设为 `true` 后，仅在服务端跳过城镇 NPC 数量和群落匹配检查，不取消其他传送条件。
- 修改配置后执行 `/reload`，环境检查开关即时生效。该开关对服务端晶塔传送判定生效，不按玩家权限单独控制。

## 升级与依赖

- 目标环境：TShock 6.1.0 / Terraria 1.4.5.6 / .NET 9；保留 `LazyAPI` 依赖和 `AdditionalPylons` 权限节点。
- 升级前备份原配置，保留已有 9 项上限，按需添加地狱、微光上限及环境开关；缺失的新字段使用上述默认值，无需覆盖已有配置。
- 如原来安装了 `FreePylons.dll`，请停服移除，避免它的同类钩子影响本插件的开关。
- `MonoMod.RuntimeDetour` 及相关运行依赖由项目配置内嵌，无需单独复制这些 DLL；`LazyAPI` 仍需由服务器提供。
- 环境钩子安装失败会输出 `FAILED` 日志，此时数量放置逻辑仍保留，但环境开关不可用。
- 数量限制沿用上游依赖客户端列表同步的放置方式，不是独立的服务端强制配额校验。
