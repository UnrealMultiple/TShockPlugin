# BottleRefund 玻璃瓶回收

- 作者: 不是现在
- 适用: TShock 6.x · Terraria 1.4.5.x

玩家每喝一瓶药水，**延迟数秒自动返还一个玻璃瓶**。发放前对时间窗内的背包流水做全面结算，
合并堆叠、快速堆放入箱、移入银行、整组丢弃、扔垃圾桶等批量操作不会误发。无游戏内指令。

## 机制

- 流水来源：背包槽变更（PlayerSlot，服务器侧槽位镜像差分）、丢地上（ItemDrop）、存箱子（ChestItemChange）
- 静默且达到结算延迟后按药水类型逐一配对：等量槽位增加→移动/合并、箱子存入→入箱、掉落→丢弃，
  均抵消；剩余"恰好 -1"才判定为喝药并返还
- 药水集合启动时全物品扫描（治疗系 + 增益系，排除食物）；瓶装水不在集合内，酿造消耗不会误判

## 配置

`tshock/BottleRefund.json`（首次运行自动生成，修改后重启生效）：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `启用` | `true` | 总开关 |
| `返还概率` | `1.0` | 每喝一瓶的返还概率（0~1） |
| `每次喝药返还数量` | `1` | 返还数量 |
| `返还物品ID` | `31` | 默认玻璃瓶 |
| `结算延迟秒` | `8.0` | 窗口越大配对越可靠，到账越慢 |
| `药水黑名单` | `[]` | 不参与返还的物品 ID |
| `流水上限` / `详细日志` | `300` / `false` | 限流与调试 |

> 已知边界：光标拖拽超过结算窗、窗内等量反取等极端时序会有 ±1 瓶出入，方向上宁漏勿错。
